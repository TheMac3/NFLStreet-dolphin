      Help

      Getting a game going, and what to do when it doesn't.

      Playing

      1. Settings: type your name. The first start gets the game ready from your Reborn install by itself (about a minute).
      2. Controllers: your Reborn controller setup is used automatically. Port 1 is you.
      3. Host: Create room, send friends the NSRB-XXXXX code, Start when everyone is listed.
      4. Join: type the code, click Join, wait for the host to start.

      If something's wrong

      1. Windows Firewall asks about Dolphin the first time: tick Private (and Public) networks and allow it.
      2. “Fingerprints differ”: everyone needs the same download and Reborn version. Pickup draft settings come from the host.
      3. Controller not responding: plug it in before starting, then Controllers → Use my Reborn controller settings.
      4. Send Mason the nsr-p*.log files from this folder if he asks.
